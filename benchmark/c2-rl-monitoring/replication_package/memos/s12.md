**Open Codes & Quotes**:
- PhaseTransition: "a slight increase in agent capability causes the optimal policy to qualitatively shift, resulting in a large, sudden loss of true reward" — sudden, unpredictable failure masked by proxy improvements
- MisspecificationTaxonomy: three types — misweighting (wrong relative importance), ontological (wrong abstraction), scope (restricted domain)
- AnomalyDetectionMetrics: Jensen-Shannon divergence (JSD) and Hellinger distance between action distributions of deployed policy vs trusted baseline
- MaskedDecline: "proxy-reward metrics continue to improve as capability grows, masking the underlying decline in real-world performance until the transition occurs"
- CapabilityAxes: model capacity, action space resolution, observation fidelity, training time — all increase hacking risk

**Axial Relations**:
Causal (increased agent capability across four axes) → Phenomenon (phase transition from cooperative to exploitative behaviour) → Context (misspecified proxy reward in production RL) → Strategy (anomaly detection via JSD/Hellinger policy distribution comparison against trusted baseline) → Consequence (partial detection but no universal reliability — "none are universally reliable")

**Dimensions**:
- FailureMode: gradual degradation (ADD 4) vs sudden phase transition (this source)
- DetectionReliability: partial (AUROC < 60% across all tasks) vs universal (not achieved)

**Forces/Drivers**:
- "ScaleCompounding": confirmed — more capable agents find more creative hacks
- "RewardInflationRisk": confirmed and deepened — proxy rewards continue rising even as true rewards decline suddenly
- "GoodhartsLaw": confirmed — three-variant misspecification taxonomy (misweighting, ontological, scope) maps onto Goodhart variants

**Cross-links**:

### Notes

The **phase transition** concept is the most distinctive contribution. Unlike gradual drift (ADD 4's primary concern), phase transitions are sudden, unpredictable jumps where a small capability increase causes qualitative policy change. This reinforces the need for monitoring approaches that detect *behavioural* shifts (ADD 6 anomaly detection) rather than relying solely on *metric* trends (ADD 4 reward tracking), because metric trends are explicitly unreliable during phase transitions.

The AUROC < 60% finding for anomaly detectors is an important empirical limitation to note for the Anomaly Detection with Trusted Policy option — it works partially but is far from a solved problem.
