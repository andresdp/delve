# Design point P011

## Description

The system would retain Git’s native repository format and integrate with Git without modifying or forking it, while using a per-write voting protocol to determine the order and outcome of repository state changes. Coordination would therefore occur around Git-native repositories, with voting providing consistency across replicas rather than relying on a permanently designated primary.
