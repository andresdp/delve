# Design point P016

## Description

A JGit repository abstraction would preserve Git operations while storing repository objects in a distributed object store rather than packfiles. Client operations would traverse commits, trees, and parents through sequentially dependent lookups in that store, retaining Git semantics but potentially limiting scalability because each traversal depends on preceding object retrievals.
