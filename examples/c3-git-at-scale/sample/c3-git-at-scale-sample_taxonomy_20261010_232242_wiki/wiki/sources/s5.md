# Introducing Scalar

## Summary

This technical announcement from Microsoft introduces Scalar, a .NET tool for improving Git performance in very large repositories. It discusses design decisions around limiting working-tree files with sparse checkout, reducing object transfer through GVFS/partial clone, and detecting changes with filesystem monitoring. It also describes incremental background maintenance for fetching, commit graphs, loose objects, and pack files.
