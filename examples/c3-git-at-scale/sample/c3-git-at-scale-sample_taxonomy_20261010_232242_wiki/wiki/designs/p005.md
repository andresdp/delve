# Design point P005

## Description

A Rails monolith provides the primary centralized repository access service, while local disk repositories serve as warm, reconstructible caches of repository data rather than authoritative replicas. This combines centralized control with cache-based resilience: disk copies can be rebuilt after failure without being treated as the durable source of truth.
