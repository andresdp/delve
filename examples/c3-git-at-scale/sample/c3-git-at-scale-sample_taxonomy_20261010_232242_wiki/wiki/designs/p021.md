# Design point P021

## Description

The system would require each repository write to obtain an exclusive lock from a majority before accepting it, preventing conflicting writes from being committed concurrently. Once authorized, the write’s content-addressed objects would be distributed individually across storage nodes rather than kept in repository-level packfiles; these choices are compatible, although the storage representation is marked rejected.
