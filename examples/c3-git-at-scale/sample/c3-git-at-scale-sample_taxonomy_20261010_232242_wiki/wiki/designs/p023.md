# Design point P023

## Description

A core Git client with standardized GVFS protocol support would access large repositories through co-located transfer-cache proxies, which serve repeated large-object requests near users and build machines. This combines a common client-side access mechanism with server-side caching to reduce repeated transfer costs; the combination is conceptually compatible, though the GVFS choice has mixed status.
