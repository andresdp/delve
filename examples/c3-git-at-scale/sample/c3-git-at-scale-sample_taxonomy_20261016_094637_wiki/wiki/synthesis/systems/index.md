# Systems

* [Cursor Continuity and Origin](/synthesis/systems/cur-cont.md) - Write-ahead log in S3 as the source of truth, repositories on disk as a warm cache.
* [GitHub filesystem distribution](/synthesis/systems/gh-fs.md) - GitHub before Spokes: NFS, GFS and DRBD filesystem distribution, then single-copy RPC fileservers.
* [GitHub Spokes](/synthesis/systems/gh-spokes.md) - Plain Git repositories replicated across servers with three-phase commit on reference updates.
* [Google JGit on a DHT](/synthesis/systems/goog-dht.md) - JGit with repository objects stored in a distributed hash table.
* [Microsoft Scalar](/synthesis/systems/ms-scalar.md) - Client-side configuration of upstream Git features: partial clone, sparse-checkout, background maintenance.
* [Microsoft VFS for Git (GVFS)](/synthesis/systems/ms-gvfs.md) - Virtualized filesystem on the client and the GVFS protocol with cache servers.
