# Design point P012

## Description

Each repository maintains at least three replicas, with Git itself distributed or modified to propagate repository state among them. Any repository instance can accept a write, relying on storage-level atomic updates rather than a consensus-elected primary; this may leave coordination details between Git-level distribution and storage-level atomicity unresolved.
