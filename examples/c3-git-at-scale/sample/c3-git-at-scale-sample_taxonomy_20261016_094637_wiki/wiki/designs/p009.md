# Design point P009

## Description

The system would use GVFS to obtain large-repository data on demand, but without the cache-server infrastructure needed for scalable access. In the background, it would incrementally repack and clean repository objects and fetch additional data while preserving local and visible remote-tracking branch references; the lack of caching may limit overall scalability.
