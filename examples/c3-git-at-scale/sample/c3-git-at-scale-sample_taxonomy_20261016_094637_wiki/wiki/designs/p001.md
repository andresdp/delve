# Design point P001

## Description

The system would incrementally run repository repacking and object cleanup in the background, while allowing any healthy server to materialize repository state without authoritative per-repository placement records. Each repository would nevertheless maintain a fixed floor of three replicas, supporting consistency, redundancy, and continued push acceptance after one failure; enforcing that replica count may require coordination despite stateless placement.
