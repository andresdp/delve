# Design point P005

## Description

An external routing table would track which machines hold each repository copy, route requests to suitable replicas, and help validate their locations. Git itself would distribute or apply repository state across those replicas, with checksums used after updates to compare their logical states; these choices are compatible, though the Git-level mechanism is marked mixed.
