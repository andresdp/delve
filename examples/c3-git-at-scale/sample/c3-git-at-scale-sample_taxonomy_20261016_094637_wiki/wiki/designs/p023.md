# Design point P023

## Description

Routing may initially target a failed or unsuitable replica; recovery selects another server and materializes the repository state there. That instance, like any repository instance, can accept writes without an elected primary, relying on storage-level atomic updates rather than consensus; stale routing and concurrent acceptance may require the underlying storage to preserve the intended write semantics.
