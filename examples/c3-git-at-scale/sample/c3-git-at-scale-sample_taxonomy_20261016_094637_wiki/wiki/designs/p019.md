# Design point P019

## Description

The system would coordinate replicated repository writes through majority agreement, rolling back writes that fail to achieve it, and use checksums to verify that surviving replicas have equivalent logical state after updates. On the client, Git index data would be streamed through a single file, making performance primarily dependent on sequential file I/O; these choices address different system layers and are not inherently in tension.
