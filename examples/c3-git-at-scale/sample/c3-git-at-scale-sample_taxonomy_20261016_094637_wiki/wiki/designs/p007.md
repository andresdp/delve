# Design point P007

## Description

Any healthy server can materialize repository state, using packfile-level replication and reference-transaction application to synchronize Git data without replicating the Git implementation. Maintenance then removes accumulated loose objects on the hosting replicas, reducing storage and lookup overhead; stateless placement means this does not depend on authoritative per-repository placement records.
