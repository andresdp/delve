# Design point P015

## Description

The system would maintain one primary repository and one additional replica, using an incrementally maintained XOR checksum to compare their logical states as changes replace old entries with new ones. Although compatible for equivalence checking, this topology remains insufficient for majority-based coordination of concurrent writes and is therefore marked rejected.
