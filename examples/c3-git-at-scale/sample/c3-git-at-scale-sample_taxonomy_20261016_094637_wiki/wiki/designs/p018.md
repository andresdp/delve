# Design point P018

## Description

Clients use partial clone to obtain only needed Git data, reducing transfer time and local storage for very large repositories. Replica consistency checks nevertheless recompute checksums from all references on every update; this is compatible, but may impose substantial verification overhead despite the efficient acquisition method.
